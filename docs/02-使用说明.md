# 使用说明（日常操作全表）

> 所有命令都用这个 python：`$py = ".local\venvs\dual-mcp\Scripts\python.exe"`（装环境时创建；
> **机器本地物**（两个 venv、模型缓存、uv 缓存、临时目录）都在 `.local\` 下，删掉会由 `install.ps1` 重建）。

### 1.1 版式：**所有书都要声明**（单栏也要写）

- **不声明**：按几何读（单栏、左右对称两栏可靠；**主+边栏会左右交错**）——所以**没有"不声明"这个选项**。
- **语法**：`页段:单栏|两栏|主副栏|三栏@切分线`；页号 = **源 PDF 物理页序**；要覆盖全部页。
  `主副栏` = 宽的那栏先读；`两栏` = 左→右；`三栏` = 左→中→右。
- **流程（两件事分开）**：
  1. **任何书**在有 S2 的 IR 之后跑一次 `layout_declare.py suggest --book <key>`（**只读，约 10 秒**）——先看它怎么说；
  2. **落盘声明是必须的**：确认后 `intake.py layout --book <key> --layout "…"`（**单栏就写 `单栏`**）；
     `主+边栏 / 三栏` 还要**用户确认切分线**（`preview` 看前后顺序再定）。
  > 为什么不能"跑完引擎就 suggest"：`suggest` 读的是 **S2 的 IR**（引擎结果的解析版），不是引擎原生输出；IR 没建出来时它没有可比的东西。
  > 没声明的书，`preflight.py` 会给一条**警告**（不阻塞）——提醒你补上，而不是替你猜。

### 1.2 三类"必须问用户"的事 + 一个"以后别问了"的开关

| 类型 | 例子 | 答复去处 |
|---|---|---|
| **版式** | 单栏 / 两栏 / 主+边栏 / 三栏（`主+边栏`、`三栏` 还要确认切分线） | `intake.py layout …` |
| **非印刷内容** | 读者手写、背面透印、印章、贴纸、装饰 —— 算不算"书的内容" | 判 `non_book_ink`（移出净版 + 登记 `errata.md`；正文一字不改） |
| **它在某个块上、但没出题** | 手写/印章/装饰所在的那一块**根本没成题**（常发生） | `judge_worklist.py flag-block --ledger s5-out/<书> --block-id <块> --basis "…" [--mode quarantine|mark]`：`quarantine`=块里**全是**非书内容 → 整块移出净版；`mark`=块里**混有印刷正文** → 正文保留、只加 `NON-BOOK-INK-MARK` 标记；`errata.md` §2b 登记；**不动队列/台账** |
| **原书疑似印错** | 公式漏字、单位写错（**影响语义**时） | 登记 `errata(kind=source_typo)`（正文照原样） |
| **页面上有、正文里没有** | 主引擎漏识了一行答案/一个名称，但见证引擎或图上确实有 | 登记 `errata(kind=missing_text)`：写 `missing_text` + **前文/后文锚点**（`anchor.before`/`after`）+ `basis`；**正文先不改**，确认后跑 `errata_apply.py` 插回（留 `MISSING-TEXT-INSERT` 痕迹；**插入会重写交付物，重跑 `pipeline_run run` 又会从 IR 重建 → 手工插回会被覆盖**） |

每次询问都会带一个默认选项：**「后续同类问题都按这个处理，不再询问」**。
你同意后就记进注册表，之后同类**不再问**：

```powershell
# 只对这本书：
& $py -X utf8 _mcp-test\intake.py ask-default --book <key> --kind non_book_ink   # 或 --kind layout
# **对所有书生效**（书级同类型答复优先）：
& $py -X utf8 _mcp-test\intake.py ask-default --global --kind non_book_ink
# 改主意（恢复每次都问）：
& $py -X utf8 _mcp-test\intake.py ask-default --book <key> --kind non_book_ink --reset
```

判定与报告里会写「**默认沿用（来源：`books.json` 的 `ask_defaults.<类型>`）**」，方便日后追溯；
`--reset` 之后**重跑**才生效——**已经落盘的判定不会被回溯改写**（要改就重判）。
- 助手的输出**不含术语**（说「OCR 显示」「窄栏」），可以直接照着问用户。

## 2. 产物一览（发布后 `s7-out\<key>\`）

| 文件 | 给谁看 |
|---|---|
| `交付说明.md` | **先看这个**：判决转述、目录清单、数字速览、已知边界、出处/分发提示（**由校验器生成，别手改**） |
| `chapter-*-clean.md` | **净版正文**（干净可用的成品） |
| `chapter-*-reviewed.md` | **留底版**（带标记与审计痕迹，用于回溯"这条为什么这样处理"） |
| `errata.md` | 三类分开：**§1 原书印错**（正文不改）· **§2 非本书内容**（已移出净版）· **§3 主引擎漏掉、页面上确实有**（正文暂缺；确认后可用 `errata_apply.py` 按锚点插回） |
| `review-kit\` | 校对包：`README-校对说明.md` + 校对表 + 页面图（给人/agent 看） |
| `report.json` | 管线报告（阶段、计数、参数、台账摘要） |
| `validation-report.json` | **22 道门禁逐条 + 证据**（机器可读的判决依据） |
| `figures\` | 落盘的图片（若原书有） |

## 3. 判决词表（`validation-report.json` 的 `verdict`）

| 判决 | 含义 |
|---|---|
| `可交付` | 无硬门禁失败、无未豁免的阻塞例外 |
| `可交付（含已豁免例外）` | 有例外但**已豁免**（豁免必须带批准人） |
| `不得交付（硬门禁失败）` | 有硬性门禁 fail → 先修，不要发布 |
| `不得交付（有未豁免的阻塞例外）` | 有阻塞例外未处理 |
| `无法判定（…）` | 缺产物 / 台账不合法 / 交付说明与产物不一致等，报告里写明原因 |

> **豁免（waiver）放哪、什么格式**：权威位置是**台账目录** `s5-out\<key>\waivers.jsonl`（产物目录里的那份只是副本，不算数）。每行一条
> `{"exception_id": "EXC-…", "reason": "…", "approved_by": "…"}`；`exception_id` 必须出现在当次 `validation-report.json` 的 `exceptions` 里；
> `approved_by` **只能是你本人**（agent 不得代批）。改完重跑 `validate_run.py`，判决才会认。

## 4. 22 道门禁一览（判据细节见 `validation-report.json` 的证据字段）

| G3 rejoin | 跨页续接与重复段落（区分"原书固定栏目重复"与"管线造成的重复"） | 软 |

| G5 footnote_bijection | 页下注 marker 集合 == 定义集合 | 软 |
| G6 figure_caption_bijection | 以源为准：源有图题则产物必须有 | 软 |
| G7 math_lint | 数学区无 `_ {` / `^ {` / 连续空格等 | 软 |
| G8 digit_unit_preserved | 数字/单位/正负号差异必须全部登记 | 软 |

## 5. 常见问答

- **只想重出产物**：跑 `pipeline_run.py run`（+ 书级用 `book`）。**不要**拿 `queue` 当"重新物化"用。
- **判定会不会丢**：重跑 `queue` 会**迁移**已判状态（不会清空）；要故意清零用 `queue --force-reset`。
- **换台机器**：拷走整个目录 → `install.ps1`（离线也行）→ 数据用 `CHEMDOC_ROOT` 指过去即可。
- **一本书不再维护**：`intake.py retire`；真删要 `remove --force`，并会在数据根留一份只追加的台账。
