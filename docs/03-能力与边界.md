# 能力与边界

> 对外承诺之前，先读完这一页。

## 1. 能做到

| 能力 | 说明 |
|---|---|
| 双引擎互证 | 两套 OCR 的原生输出**冻结留底**，差异变成"待判题目"，而不是靠单一引擎的自信 |
| 可追溯 | 每条判定带 `judge.model` / `judge.mode` 与"我看到了什么"；产物与证据一一对应 |
| 门禁化交付 | **22 道门禁**由独立校验器 `validate_run.py` 判决；**产出者不得自判** |
| 两版正文 | **净版**（直接用）+ **留底版**（带标记，可回溯） |
| 交付说明 | 交付根**自解释**（判决、目录、数字、已知边界），并带**封条**防事后篡改 |
| 校对包 | 只列"需要你判断"的条目（已分流的另列），配页面图与页码链接 |
| 可迁移 | 工具与数据可分家（`CHEMDOC_ROOT`）；离线可装（自带 `_wheels/`）；新机器空注册表合法 |

## 2. 明确不做（别期待）

- **不**做版面还原（不做 PDF 逐行坐标复刻）、**不**做公式→LaTeX 全量重写、**不**做图片矢量化。
- **不**替你判定：工具只**出题 + 收证据 + 复核判据**；"看图下结论"这一步必须有人（或你的 agent）做。
- **不**对跨页续句做语义级重排：只做**有据可查**的续接与登记。
- **不**承诺"门禁过了 = 判定判对了"：门禁查的是**可验证的形态**；**不构成对内容正确性、科学事实或完整性的保证**，判定质量取决于判的人与判据本身。**「可交付」说的就是「形态」**——内容核对看 `review-kit/校对表.md`（其中"需人工 N 条"就是要你看的部分）。

## 3. 质量口径（怎么读数字）

- 判决词表见 `02-使用说明.md` §3；**硬门禁 fail → 不得交付**，除非有**带批准人的豁免**。
- `unverified` 是**合法状态**（缺某类输入时判据无法执行，工具如实标注，不假装通过）。
- 升级率（G10）是**观测指标，永不断交付**；它的靶子只对"给人看的条数"。
- **咨询字段别当能力**：`report.json` / 画像里的 `route`、`has_text_layer`、`columns_mode`、`columns_agreement`
  **目前没有消费方**（不改变产物）；`columns_reliable=false` 的书更别信。它们只作诊断参考。

## 4. 隐私

- **云端** MinerU：会把**整页图上传**到云端 → 涉密/受限材料请改用**本地**引擎组合。
- **本地** PaddleOCR-VL：不上传（需要 GPU；可选安装，独立环境）。
- 每次运行前用 `preflight.py --book <key>` 看那一行**隐私提示**，确认符合你的要求。
- 对外分发产物时，**必须声明**是否用过云端 OCR。

## 5. 密钥

- 只存在于**你自己的**环境变量或 `%USERPROFILE%\.chemdoc\secrets.json`（工作区之外）。
- 本工具**不**把密钥写进配置、日志、产物；`secret_scan.py check` 会扫描工作区确认"密钥没落地"（只报路径、不打印值）。
- 填密钥：双击 `输入密钥.cmd`（掩码小窗）。
