# 快速开始：跑通你自己的第一本书

> 前提：已跑过 `install.ps1`（或先用 `离线演示.cmd` 看看成品长什么样）。
> **装完建议先双击一次 `离线演示.cmd`（几秒）**：它会在自制样书上跑完 22 门禁 + 交付说明，等于**这台机器能不能按文档起跑**的最小自检（跑真书不强制，但它是最快的"环境没坏"证据）。环境与文档不一致？跑 `python -X utf8 _mcp-test\doctor.py check`。

## 0. 准备

- 一本书的 PDF（或先切出**连续的一段**，比如第 1–30 页；本工作流按"切片"登记，片内页恒为 1..N）。
- 想清楚用哪种引擎组合：**云端 MinerU（要密钥、会把整页图上传）** + **本地 PaddleOCR-VL（可选、要 GPU）**。
  看一眼矩阵：`python -X utf8 _mcp-test\engines.py matrix`。

## 1. 登记这本书（会切片 + 写注册表）

```powershell
$py = ".local\venvs\dual-mcp\Scripts\python.exe"
& $py -X utf8 _mcp-test\intake.py add --pdf "D:\books\my-book.pdf" --ranges 1-30 --key my-book --label "我的书 1-30" --dry-run
# 确认无误后去掉 --dry-run 重跑（会切片到 _test-inputs\，并把条目写进数据根的书注册表）
& $py -X utf8 _mcp-test\intake.py list
```

- `--ranges` 写的是**原书页号**（`1-30`、`5`、`7,9-11` 都行）；切片后**片内页**是连续的 1..N。
- 注册表是**数据**：默认放在数据根（`paths.py show` 可看）；想换位置设环境变量 `CHEMDOC_ROOT`。

## 2. 跑两个引擎，把**原生输出**放进注册表指的地方

```powershell
& $py -X utf8 _mcp-test\intake.py list     # 看这本书的 mineru_dir / paddle_dir 在哪
& $py -X utf8 _mcp-test\preflight.py --book my-book   # 能不能跑 / 缺什么 / 大概多少批 / 隐私行
```

- **云端 MinerU**：先双击 `输入密钥.cmd` 填密钥，再用 `dual-mcp-bridge\` 里的 wrapper 跑；产物落到 `mineru_dir`。
- **本地 PaddleOCR-VL**（可选）：装了 `install.ps1 -WithPaddle` 后一条命令：
  `& $py -X utf8 _mcp-test\engines.py run --slot witness --book <书key> -- --pages 1-3`
  （**运行环境由它自动带上**：模型缓存进 `.local\paddle-home`、临时目录进 `.local\tmp`，不用手工设）。
- 引擎产物是**文件**、会被冻结留底：换引擎只是换配置，不改后面的步骤。

## 3. 出画像（版面统计，供后续判家具/分栏）

```powershell
& $py -X utf8 _mcp-test\s0_classify.py profile --pdf "_test-inputs\my-book.pdf" --out "s0-profiles\my-book.profile.json"
```

## 4. 跑管线（只写暂存区，不发布）

```powershell
& $py -X utf8 _mcp-test\pipeline_run.py run --book my-book
```

跑完会在 `s7-out\_staging\my-book\` 出产物，并在末尾给出**自校验**结果。多卷书用 `pipeline_run.py book --book my-book`。

## 5. 判定（唯一需要"看图"的一步）

```powershell
& $py -X utf8 _mcp-test\pipeline_run.py queue --book my-book          # 出题（可按页分批）
& $py -X utf8 _mcp-test\judge_worklist.py status --ledger s5-out\my-book
```

- 看 `packets\` / `crops\` 里的**裁图**（不是整页）；把结论写成一份 JSONL：
  `{"item_id": "...", "verdict": "exists|not_exists|no_content_diff|unclear|non_book_ink", "confidence": 0.9,
    "evidence": {"what_i_see": "..."}, "judge": {"model": "...", "mode": "..."}}`
- **存在性/差异类词表是这五个**：`exists` / `not_exists` / `no_content_diff`（归一后无内容差异）/
  `unclear`（看不清）/ **`non_book_ink`**（页上**不是书的内容**：读者手写、背面透印、印章、贴纸、装饰 —
  它会把该块**移出净版**并登记进 `errata.md`，正文一个字都不改）；
  **转写类**（`transcribe_region`）另用 `transcribed` + `"transcription": "…"`，或 `no_text`。
  （没有 `confirmed` / `rejected`；**判词写错时只拒那一条**、其余照写、退出码 3，界面会告诉你允许哪些词。）
- **写回前可以先预检**：`judge_worklist.py apply --ledger s5-out\my-book --verdicts verdicts.jsonl --check-only`
  （只验词表与条目，不写台账）。
- 写回：`& $py -X utf8 _mcp-test\judge_worklist.py apply --ledger s5-out\my-book --verdicts verdicts.jsonl`
- **不确定就写 `unclear`**（宁缺勿猜）；判定必须带 `judge.model` / `judge.mode`。
- **看到页面上有、正文里却没有的内容**（主引擎漏识）：判 `exists` 之外，**顺手记一条**
  `errata(kind=missing_text)`：写 `missing_text`（页上原文）+ `anchor.before` / `anchor.after`
  （**紧邻的前文结尾 / 后文开头**，句子级即可）+ `anchor.position`（整行 `own_line`、行内 `inline`）+ `basis`。
  这样读者确认后能**一键插回**（`errata_apply.py`）；正文在你确认前不改，交付说明里会点名「内容缺口」。
- **遇到这三类必须停下来问用户**（不得代答）：① 版式（任何书都要声明）；② 非印刷内容（手写/透印/印章/装饰）；
  ③ 原书疑似印错但影响语义。每次询问都带一个默认选项——「后续同类问题都按这个处理，不再询问」；
  用户同意后记进注册表：
  `& $py -X utf8 _mcp-test\intake.py ask-default --book my-book --kind non_book_ink`
  （清除恢复为每次都问：加 `--reset`）。

## 6. 校验 → 发布

```powershell
& $py -X utf8 _mcp-test\validate_run.py run --book my-book     # 22 道门禁（唯一判决者）
& $py -X utf8 _mcp-test\publish_run.py publish --book my-book  # 发布到 s7-out\my-book（旧版自动归档）
```

交付目录里会有：`交付说明.md`、`chapter-*.md`（**净版**与**留底版**各一套）、`errata.md`、
`review-kit\`（校对包）、`report.json`、`validation-report.json`。**先读 `交付说明.md`。**

## 7. 常见情况

| 情况 | 怎么办 |
|---|---|
| 只想先看流程 | 双击 `离线演示.cmd`（自制样书，9 页） |
| 门禁不过 | 看 `validation-report.json` 的 `hard_gates_failed` 与逐条证据；**不要**改报告 |
| 候选队列里有大量"其实不用人看"的项 | 用 `judge_worklist.py plan/check` 看分流统计，再按需 `waived`（豁免必须写批准人） |
| 这本书做完了、不想再维护 | `intake.py retire <条目> --why "…"`（保留条目、不再要求数据在位） |
