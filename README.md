# chemdoc-pdf-to-markdown

把**教材 / 书籍 PDF** 转成**可追溯、可交付的 Markdown** 的工作流：

```
PDF ─┬─ MinerU（云端·主引擎）        ─┐
     └─ PaddleOCR-VL（本地或云·见证）─┴─ 原生输出（冻结）→ IR → 两引擎差异出题
        → 视觉判定（校对裁图，逐条留证）→ 两版正文（留底版 / 净版）
        → 22 道门禁 + 判定台账 + 交付说明 + 校对包
```

**关键设计**：OCR引擎之后每一步都是确定性 CLI；判定是唯一需要agent"看图"的环节，
契约是**文件 + JSONL**（所以"谁判的、依据什么"全程可追溯）。

## 先看成果（不用密钥、不装 OCR、不用 GPU）

双击 **`离线演示.cmd`**。它在一份 **9 页自制样书**上跑完整流程，最后打印判决与交付目录
（`交付说明.md`、净版/留底版正文、校对包、22 道门禁的逐条证据）。

## 三步上手

1. **装环境**（要求 **Python ≥3.12**；机器上没有 3.12 时加 `-Uv` 让 uv 取一个；**要求 PowerShell 7+**，即 `pwsh`——Windows 自带的 5.1 会在参数默认值处崩，脚本已用 `#Requires` 明确拦下）
   ```powershell
   pwsh -ExecutionPolicy Bypass -File .\install.ps1
   ```
   没网也能装：本目录自带 `_wheels/`（离线 wheel 房），安装器会自动优先用它。
   想同时装**本地**见证引擎（PaddleOCR-VL，约 2 GB、需 GPU）：`install.ps1 -WithPaddle`

2. **看演示**：双击 `离线演示.cmd`（或 `python -X utf8 _mcp-test\demo_offline.py run`）

3. **跑自己的书**：见 `docs\01-快速开始.md`。一句话版：
   填密钥（只用云端时）→ `intake.py add` 登记 → 跑引擎 → `s0_classify.py profile` 出画像 →
   `pipeline_run.py run --book <key>` → 判定 → `validate_run.py run --book <key>` → `publish_run.py publish`。

## 跑引擎（不需要手工设任何环境变量）

```powershell
$py = ".local\venvs\dual-mcp\Scripts\python.exe"
& $py -X utf8 _mcp-test\engines.py run --slot witness --book <书key>          # 本地 PaddleOCR-VL（不上传）
& $py -X utf8 _mcp-test\engines.py run --slot primary --book <书key>          # 云端 MinerU（要先填密钥）
& $py -X utf8 _mcp-test\engines.py run --slot witness --book <书key> -- --pages 1-3   # 只跑几页
```
`engines.json` 里每个槽位声明的环境（模型缓存目录、临时目录、UTF-8 开关）**由这条命令自动注入**；
直接喊 runner（`_mcp-test\runners\paddle_local.py`）也会自己补上——**人和 agent 都不需要设环境变量**。

## 它不做什么

**不做**版面还原、公式转 LaTeX、图片矢量化。
**「可交付」判的是「形态」**：22 道门禁查的是**可验证的形态**，**不构成对内容正确性、科学事实或完整性的保证**；**「门禁通过」不等于「内容已核」**——内容核对看交付物里的 `review-kit/校对表.md`（其中"需人工 N 条"就是要你看的部分）。
判定环节不替你判定：工具只负责**出题 + 收证据 + 判据复核**，判的人（或你的 agent）在 `docs\03-能力与边界.md` 里说清了该怎么做。

## 适用边界（免责声明）

- **没有做过大规模异形版面测试**：目前只在若干化学教材上跑通（**单栏 / 主+边栏**，扫描版与文字版都有），
  **未系统覆盖**多栏杂志、竖排古籍、图文混排密集、表格/公式密集、手写批注较多、页面倾斜或跨页拼接等版式。
  **不保证对所有版式都生效。**
- 建议先跑 **3–5 页切片**，看 `review-kit/校对表.md` 与净版正文，再决定是否整本跑；版式请先用
  `intake.py layout` **声明**（单栏也要写），非印刷内容按 `docs/03-能力与边界.md` 先与使用者确认。
- 门禁保证的是**产物形态**（结构、链接、台账闭合），**不保证内容正确性**；内容核对以校对表与人工判定为准。
